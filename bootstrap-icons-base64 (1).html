Icon Base64 Exporter

Choose any free icon frameworks and export every icon as Base64 in a white and a dark variant, as CSV or JSON. Every icon has a transparent background, so it sits on any background colour. The white set is for dark backgrounds and the dark set is for light ones. Icon data comes live from the jsDelivr API (Iconify open-source sets).
