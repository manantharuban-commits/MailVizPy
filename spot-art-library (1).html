Clear, modern spot illustrations for banking, audit, analytics and everyday office emails and slides. Each one sits in an Outlook-safe hero card, with heading, copy and button on the left and the artwork on the right. Click any heading or line of copy to edit it, then copy the card HTML, the Base64 PNG or python-pptx code.

How these render.
  • Each illustration is a PNG drawn at 2× (540×420) and shown at 270×210, so it stays sharp on high-DPI screens. Optimised mode compresses it to a 256-colour PNG, usually 20–60 KB, and keeps the transparency.
  • Base64 images show in new Outlook, Outlook.com, Apple Mail and iOS Mail. Classic Outlook desktop and Gmail often block data: images, so for those, host the PNG or attach it by CID and swap the src.
  • The heading, copy and button are plain table HTML, so the message still reads if the image is blocked.
  • For PowerPoint, pick the 3× or 4× size and use Copy python-pptx. The background is transparent, so the art sits on any slide colour.
